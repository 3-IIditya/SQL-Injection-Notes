# 🔐 SQL Injection (SQLi) Notes

A collection of my **SQL Injection (SQLi) learning notes**, created while studying web application security through [PortSwigger Web Security Academy](https://portswigger.net/web-security/sql-injection).

This repository documents my learning journey, practical concepts, attack techniques, and prevention methods related to SQL Injection.

## 📚 Topics Covered

- **SQL Injection Fundamentals:** Understanding SQLi and identifying potential vulnerabilities.
- **UNION-Based SQL Injection:** Determining column counts, finding compatible data types, and retrieving data.
- **Database Enumeration:** Identifying database types and exploring database schemas.
- **Blind SQL Injection:** Boolean-based, time-based, and conditional-error techniques.
- **Error-Based SQL Injection:** Using database errors to extract information.
- **Out-of-Band (OAST) SQL Injection:** Understanding out-of-band techniques.
- **Advanced Scenarios:** SQLi in JSON, XML, cookies, and second-order injection.
- **SQL Injection Prevention:** Parameterized queries and secure coding practices.
